◆ PS 18 — SensorSentry: How Cross-Validation Works

The system cross-validates multiple sensor sources in real-time: GPS ↔ IMU (via EKF innovation consistency / Chi² gate), Barometer ↔ GPS Altitude (environmental cross-check), and IMU Anomaly Detection (bounds checking for false/injected readings). Each sensor receives a Trust Score (0–100%) based on cross-validation results. When GPS spoofing, IMU injection, or environmental manipulation is detected, the SAARM module automatically isolates compromised sensors and switches to safe inertial-only navigation.
